# Module 08 — Client-Ready Deliverables

> Duration: ~70 min · Prerequisites: M06, M07 · Produces: one Direction Deck end-to-end

## Learning objectives

1. Match output packages to business moments (teaser vs deck vs hero set vs boards).
2. Enforce set-level consistency without breaking provenance.
3. Present renders as decisions, ending meetings with chosen directions.

---

## Lesson 8.1 — Deliverable taxonomy (15 min)

| Package | Contents | Turnaround | Built from |
|---|---|---|---|
| Concept teaser | 5-concept contact sheet + one-liners | same day | sprint PACKAGE phase |
| Direction deck | 2–3 developed renders + move rationales + precedent strip | 1–2 days | sprint keepers → RenderForge craft passes |
| Marketing hero set | 4–6 finals, multi-view, graded consistently | 2–4 days | approved direction → full bank treatment |
| Board kit | print-res crops, diagram overlays, section blends | project-dependent | hero set + design team |

Rule: never skip taxonomy steps. Jumping straight to hero set = crafting beauty for undecided directions.

## Lesson 8.2 — Consistency grading (20 min)

A delivered set must feel like ONE photo shoot:

- same lighting family (don't mix overcast study + golden-hour hero)
- same population level
- same aspect logic within a spread
- unified grade (pick house sentence from custom instructions)

Method: re-render stragglers rather than photoshopping mismatched frames. Regeneration preserves provenance chains (Red Rule 6); retouching severs them.

Consistency pass protocol:
1. Lay set side-by-side at thumbnail size — mismatches pop at thumbnail scale
2. List deviations by slot (which bank caused it)
3. Re-render deviants with corrected banks; craft tier
4. Re-audit thumbnails

## Lesson 8.3 — Honesty layer (15 min)

Every package carries:

- Disclosure line verbatim from firm policy (Rule 3)
- "Indicative imagery — design development ongoing" footer where unresolved details show
- Optional but recommended: before/after strip (base model vs render). Costs two minutes; buys disproportionate trust — clients see the discipline behind the magic.

Placement standard: disclosure bottom-left, 60% opacity min, never hidden in metadata only.

## Lesson 8.4 — The presentation script (20 min)

Present renders as decisions, not pictures:

1. **Frame the fork:** "We developed five directions; they differ in how the building meets the street."
2. **Lead with moves:** "This option lifts the volume to return the ground floor to the public."
3. **Show evidence:** image supports the sentence — never the reverse.
4. **Close the loop:** "Which direction should we develop?" — the meeting's actual goal.

Anti-pattern: silent slideshow. Images without narratives invite clients to direct design via adjective feedback ("make it warmer") instead of decision feedback ("direction 3").

LAB: build one full Direction Deck from your Gate 7 sprint keepers:

- [ ] 2–3 keepers advanced via RenderForge craft passes
- [ ] Move rationales written per keeper
- [ ] Precedent strip (3 refs with rights notes)
- [ ] Honesty layer applied
- [ ] Thumbnail consistency audit passed
- [ ] Presented aloud to ≥1 colleague using the script

- [ ] Presentation delivered live once (record it if solo)

## Quiz

1. Why re-render instead of retouching mismatched frames?
2. What does leading with moves prevent?

<details><summary>Answers</summary>
1. Provenance integrity (Rule 6) plus genuine slot-consistency fixes.
2. Adjective-feedback loops; keeps meetings on decision rails.
