## Conventions used across all files

- `CONCEPT → DEMO → LAB → GATE → ARTEFACT` rhythm in every module.
- Gates are pass/fail checklists; artefacts land in your studio folder (see M00).
- Slot placeholders use `{{double_braces}}`; dropdown banks use `BANK n` labels.
- Templates are versioned (`v1.0.0`); never edit a frozen instance.
