## Context and Problem Statement

Agency OS must serve as a self-hostable, auditable AI agency: 24 agent contracts, deterministic orchestration, human-in-the-loop gates, and full traceability — on a solo-founder budget (10h/week). How to isolate pure orchestration from LLM nondeterminism, enforce governance in code, and keep deploys reversible?

## Decision Drivers

- Determinism & testability (235 tests, no flake)
- Traceability (PRD→ticket→PR→test→release→doc per P2)
- Least-privilege (TOOL_RISK 25/25)
- 12-Factor + encrypted workflow state

## Considered Options

1. **Chosen: Fastify + deterministic orchestration package** — `packages/orchestration` pure, `SkillRuntime` with injectable `runStep` harness, `JobQueue` polling.
2. LLM-first orchestrator (LangGraph-style) — rejected: untestable, governance afterthought.
3. Temporal/queue-heavy orchestration — rejected: ops burden for solo founder.

## Decision Outcome

- **Control plane:** Fastify, SQLite (local)/Postgres (prod), `WorkflowEngine` with fan-out + `lowRiskSkip`, `MissionCompiler`/`CapabilityRouter`/`computeReachability`.
- **Agent contracts:** `agents.ts:82` — 12-field `AgentDefinition`, `tierBudget` risk-weighted, `TOOL_RISK` permission matrix.
- **Security/compliance:** `OrgKeyEncryption` for `workflow_runs`, `hashContent` evidence registry, RBAC per `TOOL_RISK`.
- **Delivery:** trunk-based, `PROJ-###`, protected `main`, 13-stage `enterprise-feature` (6 fan-outs).

## Consequences

- **Positive:** Testable without LLM, 100% roster (24/24) via workflows, 4× concurrency.
- **Negative:** `pm_decompose` still needs app-layer enqueue (GAP-005); governance docs now required (this ADR is first of many).
