## Process (P2 traceability + Hard Rule 9)

1. New asks that change approved PRD/design → file a `CR-###` here (never silent scope creep).
2. PM estimates impact × risk; Principal/Human approves or rejects at G0/G1.
3. Approved CR → ticket `PROJ-###` + PRD amendment + decision log entry.
4. Rejected CR → reason recorded, original scope unchanged.

